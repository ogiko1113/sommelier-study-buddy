
## Diagnosis

The issue is a TanStack Router file naming conflict. We currently have:

- `src/routes/_authenticated.editor.tsx` — defined as `/_authenticated/editor` (the list page)
- `src/routes/_authenticated.editor.new.tsx` — defined as `/_authenticated/editor/new`
- `src/routes/_authenticated.editor.$id.tsx` — defined as `/_authenticated/editor/$id`
- `src/routes/_authenticated.editor.import.tsx` — defined as `/_authenticated/editor/import`

In TanStack Router's flat file convention, `_authenticated.editor.tsx` is treated as a **layout route** for `/editor` because child routes (`.new`, `.$id`, `.import`) exist beneath it. As a layout it must render an `<Outlet />` for children. Since it instead renders the list UI directly with no `<Outlet />`, every child URL falls back to showing the layout content (the list).

The conventional fix is to split the dual role:

- Rename `_authenticated.editor.tsx` → `_authenticated.editor.index.tsx` (this becomes the `/editor` index route showing the list)
- Add a new `_authenticated.editor.tsx` as a tiny layout route that just renders `<Outlet />`

This way `/editor` matches `editor.index`, and `/editor/new`, `/editor/$id`, `/editor/import` match their files inside the editor layout.

## Plan

### 1. Create layout shell `src/routes/_authenticated.editor.tsx`
Tiny layout that just renders `<Outlet />`:
```tsx
import { createFileRoute, Outlet } from "@tanstack/react-router";
export const Route = createFileRoute("/_authenticated/editor")({
  component: () => <Outlet />,
});
```

### 2. Rename current list to `src/routes/_authenticated.editor.index.tsx`
Move all current contents of `_authenticated.editor.tsx` (the list page with filters, pagination, etc.) into a new file `_authenticated.editor.index.tsx` and change the route path to `/_authenticated/editor/`:
```tsx
export const Route = createFileRoute("/_authenticated/editor/")({
  component: EditorListPage,
});
```
Everything else in that file stays exactly the same.

### 3. Leave child routes untouched
`_authenticated.editor.new.tsx`, `_authenticated.editor.$id.tsx`, `_authenticated.editor.import.tsx` already have correct paths and need no changes.

### 4. Route tree
`src/routeTree.gen.ts` is auto-regenerated by the TanStack Router Vite plugin on next build/dev — no manual edit needed.
